# Naveen Kumar S - Developer Portfolio

A personal developer portfolio website for **Naveen Kumar S**, built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Icons**: Lucide React, Custom SVG Icons
- **Effects**: Typewriter effect, animated counters, particle confetti
- **Typography**: Plus Jakarta Sans, JetBrains Mono

## 🛠️ Getting Started
```bash
# Clone the repository
git clone https://github.com/Naveenkumar2007cit/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
